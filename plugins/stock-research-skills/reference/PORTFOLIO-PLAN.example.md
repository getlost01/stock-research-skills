# Portfolio Plan

**This is the template.** Copy it before filling anything in:

```bash
cp PORTFOLIO-PLAN.example.md PORTFOLIO-PLAN.md
```

`PORTFOLIO-PLAN.md` is git-ignored, so your real allocation, holdings,
bonds, and SIP amounts stay on your machine. Never put real figures in
this example file.

Fill the copy in once so the skills (`rebalancing-planner`,
`tax-capital-gains`, `portfolio-review`, `bond-ladder-planner`,
`rate-watch`, `sip-review`, `dividend-income`) have something concrete to
compare against instead of guessing. Edit anytime your goals/risk
appetite change.
